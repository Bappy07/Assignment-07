BazarDor (বাজার দর)
About the Project
BazarDor is a web project where users can browse products and check their prices. The main goal of this project is to make it easier for people to find product information and make better shopping decisions.
1.Technologies Used
- Next.js
- TypeScript
- Tailwind CSS
- daisyUI
- MongoDB
- Better Auth

2.Key Features
1. Users can browse different products.
2. Users can view product prices and details.
3. Products can be organized by category.
4. Users can create an account and sign in.
5. The website works on desktop and mobile devices.

 3.How to Run the Project
1. Clone the repository.
2. Run `npm install`.
3. Set up the required environment variables in `.env.local`.
4. Run `npm run dev`.
5. Open `http://localhost:3000` in your browser.

4.Project Status
This project is currently under development.
